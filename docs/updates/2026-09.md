## U-20260923-02 · 2026-09-23 · MCP server answers again: JSON-RPC over stdio without the SDK · #done #mcp #bugfix

Importing the package imports locust, and `locust/__init__.py` calls gevent `monkey.patch_all()`; the `mcp` SDK's stdio transport reads stdin on an anyio worker thread, which after patching is a greenlet that never gets scheduled while asyncio blocks the main thread. Reproduced with a ten-line SDK server: it answers without `import locust` and stays silent with it (mcp 1.30.0, locust 2.46.6, Python 3.12, Windows). With mcp 2.x (since 2026-07-28) it failed earlier still: `Server.list_tools` no longer exists.

## U-20260923-09 · 2026-09-23 · Report generators tested; service map follows real request order · #done #bugfix #tests

- **Bug found while testing** (first step of `progress.md` #1): `build_service_map` claims to chain requests in time order, but it concatenated `test_record_list` (successes) and `error_record_list` (failures), and records carried no timestamp. As soon as one request failed, the map had edges between requests that were never consecutive and lost the real ones — `/login` ok → `/cart` failed → `/checkout` ok came out as `/login → /checkout → /cart`. The Allure writer had the same blind spot and stamped every result "finished now".
- **Fix**: the request hook stores Locust's `start_time` (epoch seconds) on both kinds of record; `build_service_map` sorts by it (stable, so older records without it keep their list order); Allure uses it for `start`/`stop`. The record field is documented in README and the test-record pages (en, zh).
- **Tests**: `test/test_report_generators.py` (8): the hook stores `start_time`; the service map follows request order across successes and failures (fails on the old code) and honours `min_weight`; cost arithmetic and its JSON file; SARIF lists each failure plus extra records; Allure writes one result per record with the recorded start and a 10 ms duration, plus `environment.properties`; the CycloneDX SBOM lists installed distributions with `pkg:pypi/` purls. Full suite: 334 passed, 5 skipped.
