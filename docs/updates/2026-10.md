## U-20261001-07 · 2026-10-01 · The control socket server moves to je_action_core · #migration #socket-server #L-6

- **What**: ActionCore's `progress.md` #2. The control server's own accept loop, framing, token check and TLS wrapping are replaced by je_action_core 0.0.2: `EnvelopeTokenRequestHandler` with `socket_server_settings(framed, token, certfile, keyfile)`. `start_load_density_socket_server` keeps its signature. It still calls `monkey.patch_all()`, then blocks on the server's `close_event` and returns the stopped `ActionTCPServer`.
- **Behaviour kept**: `test/test_socket_server.py` (U-20261001-03's 15 characterization cases, committed in `472b89a` before the move) passes unchanged against the new server. Only its `_exchange` helper changed, from building the old `TCPServer` to building the core handler. The cases cover:
  - raw and framed replies;
  - `Error: <text>` failures;
  - the envelope token, refusals and quit;
  - an empty request, and a bad frame length.
- **Small differences, by design**:
  - `quit` takes effect immediately; the old accept loop noticed it only on the next connection.
  - TLS is wrapped on the connection's own thread instead of in the accept loop, so a slow handshake no longer blocks other clients.
  - A failed request is also logged to stderr.
- **Also**: a new `test/test_socket_server_process.py` runs the real server in a child process under gevent, runs an action and stops it. It polls rather than calling `communicate()`, because the gevent-patched test process can block in it on Windows. The API and socket docs (En, Zh) name the new class and say the call blocks until the server stops. `architecture.md` §6 describes the socket settings. The minimum becomes `je_action_core>=0.0.2` (`pyproject.toml`, `dev.toml`, both requirements files, `uv.lock`).
- **Result / numbers**: 1189 passed, 2 skipped.
- **Files**: `je_load_density/utils/socket_server/load_density_socket_server.py`, `test/test_socket_server.py`, `test/test_socket_server_process.py`, `docs/source/api/utils/socket_server.rst`, `docs/source/{En,Zh}/doc/socket_server/socket_server_doc.rst`, `architecture.md`, `pyproject.toml`, `dev.toml`, `requirements.txt`, `dev_requirements.txt`, `uv.lock`.
